# Countries of the World

**[Play →](https://countries-game-khaki.vercel.app)**

[![Countries of the World](preview.jpg)](https://countries-game-khaki.vercel.app)

Name all 196 countries in 15 minutes. Then do it again with flags, capitals, country by capital and population.

- Answers in English or Russian, forgiving of case, hyphens and typos in diacritics
- Progress and records survive reloads
- Achievements, 3D medals and a leaderboard
- One-tap login with Telegram — no passwords; shared with my other games

**Stack:** Vite, vanilla JavaScript, d3-geo + TopoJSON for the maps, serverless API on Vercel.

```bash
npm install
npm run dev
```
